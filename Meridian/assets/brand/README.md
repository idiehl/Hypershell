# Meridian: kinetic spindle

The Meridian mark develops the user's spinning-top sketch into a long champagne-gold spindle, opposing curved cross-arms, and cyan/violet elliptical motion trails. The small crown and tapered lower axis retain the reference's silhouette.

`meridian.png` is the transparent original generated with the built-in image-generation tool. `meridian.ico` packages that artwork at 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixels. Rebuild the ICO with `pwsh -STA -File scripts/package-brand-icon.ps1`; this resizes and packages the artwork without redrawing it.

The MyNet package keeps both files in `app/assets/brand/` and points its registration at `app/assets/brand/meridian.png`. Future Windows host builds embed `meridian.ico` as the executable icon. The editor serves favicon copies from `app/wwwroot/brand/`; standalone publications remain self-contained. No external service or font is needed.
