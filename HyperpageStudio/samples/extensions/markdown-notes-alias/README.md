# Markdown Notes Alias sample

Copy this folder into Hypershell's device-local `extensions` directory, then
open **Settings > Extensions** and refresh discovery.

The package contributes one static mapping: `.hnote` files use Hypershell's
built-in Markdown language mode, heading outline, guarded source mutations, and
HTML/Word exporters. It contains no entry point and receives no executable,
file, terminal, network, secret, or AI capability.

Core-owned extensions and extensions claimed by multiple packages are left
dormant. The Extensions settings card reports the mapping state and reason.
