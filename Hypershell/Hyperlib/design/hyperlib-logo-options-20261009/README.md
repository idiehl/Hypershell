# Hyperlib logo concepts

Ten vector concepts for the compact native Hyperlib toolbar. The user selected **03, Shell pages**. These use the actual approved Hypershell spiral shell as the family reference, its mint `#A3C7BD`, and an open book or other library cue. The other nine concepts remain preserved as design history.

Open `index.html` for dark/light comparisons, 16/20/24/32 px specimens, and an interactive toolbar preview. `contact-sheet.svg` is a portable static comparison. Each numbered SVG is self-contained, transparent, and editable with a 24-unit view box. SVGs use `currentColor`; their default is brand mint.

1. **Shell book** (`01-shell-book.svg`) — The Hypershell shell and paired spiral trails, with an open book replacing the cube.
2. **Orbit book** (`02-orbit-book.svg`) — An open book framed by the shared spiral motion. Removing the shell ring gives the book more room.
3. **Shell pages** (`03-shell-pages.svg`) — The shell itself becomes two curved pages. A central spine turns the familiar oval into a library mark.
4. **Shell folio** (`04-shell-folio.svg`) — A single upright volume in the shared shell. Its folded corner recalls the facets in Hypershell's cube.
5. **Shell H** (`05-shell-h.svg`) — A restrained H inside the spiral shell, using the same rounded outline and mint as Hypershell.
6. **Linked leaves** (`06-linked-leaves.svg`) — Two overlapping page facets sit inside the orbit. Their angular overlap comes from the shared cube.
7. **Library shell** (`07-library-shell.svg`) — Three simple book spines nest inside the familiar shell. A compact shelf suggests an entire collection.
8. **Turning pages** (`08-turning-pages.svg`) — An open book uses two sweeping leaves to echo Hypershell's paired motion trails without the enclosing shell.
9. **Open shell** (`09-open-shell.svg`) — A pared back circular shell opens into an orbit around the book. One continuous sweep keeps the mark airy.
10. **Volume cube** (`10-volume-cube.svg`) — Hypershell's three face cube becomes a dimensional volume. Its central seam reads like a book spine.

**Selected: 03, Shell pages.** The shell itself becomes two curved pages with a central spine. The production native toolbar, web logo/favicon, and MyNet icon use this selected artwork.

The native selected resource `src/Hypershell/Assets/Brand/hyperlib-shell-pages.xaml` mirrors option 03 as `DrawingImage` key `HyperlibLogo` and uses its scoped `HyperlibBrandBrush` in fixed brand mint `#A3C7BD`. The earlier `hyperlib-shell-book.xaml` draft remains preserved as design history.

Source references: `src/Hypershell/Assets/Brand/hypershell-spiral-shell.svg`, its accompanying brand documentation, and the previous `Hyperlib/src/HyperLib.Host/wwwroot/favicon.svg` open-book mark.
