# Base Template Library

Seventeen reusable starters: the two original designs and fifteen additional designs. In HyperLib, create a Work and choose a starter. Every new work receives its own template, components, theme, and default page content. Add Page reuses that work's defaults.

Each folder includes reference snapshots authoring.template.json and default-page.json, plus a complete Studio Project. Project/authoring.template.json is the canonical reusable schema used for new Works; the top-level JSON files document the shipped design. Open Project/visual-page.project.json in Hyperpage Studio to edit the reusable source. The projects use the HyperLib runtime SDK under this library root. Existing works do not track edits to these source packages.

The Base Template Library collection contains the fifteen additional design demos. Its installation is one reversible content batch. Forms show a local confirmation without sending or storing entries; maps and web embeds load only when activated.
