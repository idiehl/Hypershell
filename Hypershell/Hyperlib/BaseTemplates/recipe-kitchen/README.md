# Recipe Kitchen

A recipe card with a wide hero, ingredient sidebar, method column, and useful kitchen timer.

Category: Food.

Create a Work in HyperLib and select this starter. The Project folder is a permanent, independently editable Hyperpage Studio project. Its authoring.template.json is the canonical schema copied into new Works; the top-level JSON files are shipped reference snapshots. It references the HyperLib runtime SDK shipped in this library.
