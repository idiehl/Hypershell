# PowerShell File Essentials sample

This package demonstrates the `ContentOnly` Hyperlib path. It contains no
runtime entry point and requests only `LibraryContent`.

Use **Settings > Extensions > Install folder** to validate and install this
unpacked sample. **Pack folder** creates a deterministic `.hyperlib` archive
that can be distributed and installed with **Install archive**.

Hypershell stages the source outside the active catalog, then validates the
package manifest, package hash, Hyperlib schema, names, language boundary,
guides, parameters, examples, and package-contained assets before activating
the library in the Command Lexicon. No executable extension approval is
involved. Updates and removals preserve the previous folder in the device-local
recovery area.
